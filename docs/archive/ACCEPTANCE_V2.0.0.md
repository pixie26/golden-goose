## 重跑方法

```bash
npm ci
npm run verify
```

真实数据库检查使用名称含 `test` 的专用测试库（测试会重建其中的 `bank_state`）：

```bash
TEST_DATABASE_URL='postgresql://…/goose_test?sslmode=require' node --test tests/postgres-integration.test.mjs
```

可选 `TEST_DATABASE_CA_CERT`（配合 `verify-full`）和 `TEST_DATABASE_POOLER_URL`（经事务池检查锁等待）。不要把测试连接指向生产数据库，也不要把连接信息写入仓库。
