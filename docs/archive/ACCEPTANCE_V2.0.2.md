## 最终股票成交逻辑

| 步骤 | 规则 |
|---|---|
| 下单 | 买入填金额，金额先冻结；卖出填股数，股数先冻结 |
| 定成交日 | 成交日收市前下单 → 当天收盘价；收市后、周末或休市下单 → 下一交易日收盘价。平时 16:00 收市；半日市港股 12:00、美股 13:00 |
| 撤单 | 成交日收市前 Olivia 可撤单；收市后不能撤单，避免看到收盘价再决定 |
| 取价 | 收市 1 小时后才把 Yahoo 日线当作确认的收盘价 |
| 结算 | 正式网站每天香港时间 17:30、06:30 自动抓取并结算，每次重试全部待成交订单；家长也可手动结算 |
| 计算 | 买入股数 = 冻结金额 ÷（收盘价 × 汇率），6 位小数向下取整，扣款向上取整到分，余额退回；卖出所得向下取整到分，按平均成本计算盈亏。港币 1:1，1 美元 = O$8 |
| 顺序 | 同一股票按成交日、提交时间依次结算；其他股票互不影响 |
| **成交日没有收盘价** | **只要这只股票之后已经有收盘价，就按之后第一个收盘价成交**，订单显示“原定 X 休市或无收盘价，已顺延”。之后还没有价格时继续等待，不会因为行情迟到而提前顺延 |
| 一直没有收盘价 | 退市或长期停牌时，家长可在成交日收市后撤销订单；买单退回资金，卖单解冻股票，Olivia 收到通知 |

一句话：**每笔订单按下单之后的第一个收盘价成交。** 所用价格一定是下单之后才公布的，不存在“先看答案再下单”。

## 本轮修改

1. **自动顺延（RGG-014）。** 成交日收盘已确认、当天没有收盘价、而之后已有收盘价时，订单改用之后第一个收盘价，并记录原定日期。先检查已存的结算报价，再检查两年日线历史，因此修剪过的旧报价也能正确顺延。
2. **日历不再需要更新（RGG-015）。** 美股 2029 年起按 NYSE 规则计算元旦、马丁·路德·金纪念日、总统日、耶稣受难日、阵亡将士纪念日、六月节、独立日、劳动节、感恩节、圣诞节及周末顺延规则，以及 7 月 3 日、感恩节次日、平安夜的 13:00 收市。港股 2028 年起按规则计算平安夜、除夕和农历年三十的半日市。港股全日假期改由自动顺延处理。删除 90 天提醒及 `calendarCoverage` 字段。
3. **家长撤销卡住的订单（RGG-016）。** 新操作 `order.cancel`，仅限家长，且必须在成交日收市后；撤销后同一股票后面的订单立即继续结算。
4. **提示更准确（RGG-017）。** 只是在等收盘价时不再显示红色提示；旧提示在下次结算时自动清除。
5. **批量登记价格（RGG-018）。** `quote.batch` 先保存整批价格再结算。
6. **页面。** 移除“特殊休市 · 顺延”按钮；过期订单显示“撤销订单”；手动登记表单默认填入最早缺价的股票和日期，并说明要从最早缺价日开始逐日登记；手机窄屏上的顺延说明单独换行显示。
7. **性能。** 每个市场复用一个时间格式器。随机模拟单次从 12.5 秒降到 3.1 秒，解析日线和结算也相应加快。

`order.roll`、`order.retarget` 接口保留，兼容旧页面及旧订单。

## 已知的小差别（设计如此）

- 港股 2028 年起的全日假期没有内置。订单会先显示那天为成交日，当天 16:00 后 Olivia 不能再撤单；成交价与完整日历相同。
- 如果 Yahoo 恰好漏掉某个正常交易日的日线，而之后的日线正常，订单会按之后第一个收盘价成交（视为当天没有交易）。
- 家长手动登记较晚日期的价格时，更早缺价的订单会按这个价格成交。页面已提示从最早缺价日开始登记，表单也会默认填入该日期。
- 交易所以后若改变半日市安排而规则没有覆盖，当天下午的订单可能按中午已公布的收盘价成交。只影响个别订单，不会造成账目错误。

## 部署后完成这五项验收

1. **环境与登录：** 完整源码通过 Git 连接部署，配置 Functions 范围的 `DATABASE_URL`、`SETUP_TOKEN`，按所选 TLS 模式配置 `DATABASE_CA_CERT`；家长、Olivia 分别登录、退出。
2. **持久化与同步：** 在独立测试库记一笔小额入账，刷新、重新登录及重新部署后仍存在；两台设备能看到同一账本变化。
3. **完整资金流程：** 在测试库完成购物申请 → 家长批准 → 申请退款 → 家长批准，以及借款 → 全部还清；核对余额、冻结和流水各只发生一次。
4. **行情与计划任务：** 搜索港股 / 美股，核对返回代码和报价日期；执行家长“抓取日线并结算”，在 Netlify 对 `daily-settlement` 使用 Run now，再观察计划执行日志。成交日当晚还没有收盘价时，订单应继续待成交；之后出现收盘价时，按之后第一个收盘价成交。
5. **常用设备：** 用实际 iPhone / iPad 检查登录、输入、导航、五个家长分页、头像上传及弹窗。

生产账本只记真实备付资金；以上演练优先使用独立测试数据库。已有账本直接沿用，不要重新初始化。

## 产品边界

Yahoo 为非官方接口，可能限流、延迟或中断；出现这些情况时订单会继续等待，或明确提示原因。分红、拆合股、代码变更等公司行动仍需人工核对。退市可以由家长撤销卡住的订单，但持仓估值仍需人工处理。
